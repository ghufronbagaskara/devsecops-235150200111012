# labs/

Satu folder per Lembar Kerja. Salin [`_TEMPLATE_LK.md`](_TEMPLATE_LK.md) ke tiap folder.

Folder yang diharapkan:

| Folder | LK |
|---|---|
| `LK01-setup/` | Setup Docker & GitHub |
| `LK02-recon/` | Deploy app rentan & recon |
| `LK03-sca-secret/` | Basic scan: SCA & secret |
| `LK04-sast/` | SAST Semgrep |
| `LK05-dast/` | DAST ZAP |
| `LK06-exploit/` | Eksploitasi SQLi & XSS (+ `bukti/`) |
| `LK07-cicd/` | Pipeline CI/CD |
| `LK08-dast-ci/` | DAST dalam pipeline |
| `LK09-hardening/` | Hardening container & secret |
| `LK10-secure/` | Aplikasi secure + monitoring/IR |

Tiap folder wajib memuat: langkah, bukti (ber-watermark `ds-<NIM>`), pemetaan OWASP, dan **refleksi**.
